## Sobre la capacitación

Este repositorio reúne la documentación técnica, los contenidos formativos, los ejercicios prácticos y los recursos de aprendizaje correspondientes a la capacitación **Microsoft Azure Administrator**, dictada por Dakota Bazan en el marco de Grupo Intertron Education.

La formación aborda la administración de infraestructura en Microsoft Azure, incluyendo gestión de identidades, gobernanza, redes virtuales, almacenamiento, recursos de cómputo, copias de seguridad y monitorización.

El objetivo es que los participantes desarrollen conocimientos y habilidades prácticas para implementar, configurar, administrar y supervisar recursos y servicios de Azure.

## Objetivos de aprendizaje

Al finalizar la capacitación, los participantes podrán:

- Administrar identidades, usuarios, grupos, suscripciones y permisos en Azure.
- Implementar controles de gobernanza mediante Azure Policy y Azure RBAC.
- Configurar redes virtuales, subredes, grupos de seguridad, rutas y conectividad.
- Implementar y administrar cuentas de almacenamiento, Azure Blob Storage y Azure Files.
- Crear y administrar máquinas virtuales y otros recursos de cómputo.
- Configurar soluciones de copia de seguridad y recuperación.
- Supervisar recursos mediante Azure Monitor, alertas, Log Analytics y Network Watcher.
- Utilizar Azure Portal, Cloud Shell, Azure CLI y PowerShell para tareas de administración.

# Programa de contenidos

## Módulo 1. Requisitos previos para administradores de Azure

**Contenidos:**
- Azure Resource Manager (ARM).
- Introducción a Azure Cloud Shell.
- Fundamentos de Bash.
- Introducción a PowerShell.
- Herramientas y entornos para la administración de Azure.

## Módulo 2. Administración de identidades y gobernanza en Azure

**Contenidos:**
- Microsoft Entra ID.
- Creación y administración de usuarios y grupos.
- Administración de suscripciones.
- Configuración de Azure Policy.
- Control de acceso basado en roles (Azure RBAC).
- Restablecimiento de contraseñas mediante SSPR.
- Principios de gestión de identidades, permisos y gobernanza.

## Módulo 3. Configuración y administración de redes virtuales

**Contenidos:**
- Configuración de Azure Virtual Network.
- Subredes y direccionamiento IP.
- Network Security Groups (NSG).
- Emparejamiento de redes virtuales (VNet Peering).
- Enrutamiento y puntos de conexión.
- Azure DNS.
- Azure Load Balancer.
- Azure Application Gateway.
- Gestión del tráfico de red.
- Conectividad y resiliencia de la infraestructura.

## Módulo 4. Implementación y administración del almacenamiento

**Contenidos:**
- Configuración de cuentas de almacenamiento.
- Azure Blob Storage.
- Seguridad y control de acceso al almacenamiento.
- Azure Files.
- Azure File Sync.
- Azure Storage Explorer.
- Carga, descarga y administración de datos.

## Módulo 5. Implementación y administración de recursos de cómputo

**Contenidos:**
- Creación y configuración de máquinas virtuales.
- Disponibilidad de máquinas virtuales.
- Administración de máquinas virtuales mediante Azure CLI.
- Azure App Service Plans.
- Implementación y administración de Azure App Service.
- Azure Container Instances.
- Creación de máquinas virtuales Windows.
- Publicación y alojamiento de aplicaciones web.

## Módulo 6. Supervisión y copias de seguridad de recursos de Azure

**Contenidos:**
- Fundamentos de Azure Backup.
- Configuración de copias de seguridad de máquinas virtuales.
- Azure Monitor.
- Log Analytics y análisis de registros.
- Network Watcher.
- Configuración de alertas.
- Supervisión de máquinas virtuales.
- Análisis de eventos y visibilidad operativa de la infraestructura.

## Buenas prácticas

Los materiales y ejercicios de este repositorio deben seguir criterios de calidad técnica y seguridad:

- Utilizar documentación oficial como referencia.
- Explicar los objetivos, requisitos previos, procedimientos y resultados esperados de cada práctica.
- Aplicar el principio de mínimo privilegio.
- No publicar credenciales, claves, tokens ni información sensible.
- Identificar los posibles costos asociados a los recursos de Azure utilizados en los laboratorios.
- Validar los comandos y procedimientos antes de incorporarlos a los materiales de formación.
